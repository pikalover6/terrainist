Terrainist — interactive codebase map

Text prompt → downloadable Minecraft world .zip. An LLM (GPT 5.6 Luna via OpenRouter) authors a deterministic spec language called Loam; a pure-TypeScript compiler turns Loam into a Java 1.21.11 (DataVersion 4671) world. The compiler is deterministic — same document + seed → byte-identical world, forever, no model in the loop — and verified by a 27-rule physics lint that reads the emitted world back off disk and refuses findings.

The two moats

1 · Determinism

▸
Every random draw seeded hash(worldSeed, nodePath); xoshiro256** RNG, position-keyed draws, BLAKE3 throughout.
▸
No wall-clock in the compiler: chunk LastUpdate, region timestamp sector and level.dat LastPlayed are pinned/zeroed (stamped at install only).
▸
No unseeded Math: 15° trig table (TRIG_SCALE=4096), pinned transcendentals; a test forbids Math.* transcendentals in dist.
▸
Byte-identity harness: git worktree + diff of decompressed chunk NBT (raw zlib framing drifts run-to-run).

2 · Correctness (27-rule physics lint)

▸
Reads the emitted world back off disk: no floating blocks, no doors into walls, no unreachable stairs, no unstable fluid, no unsupported furniture.
▸
Walking agent checks reciprocal-move connectivity (takes 3-block drops — floods downhill, so "connected" is climbable).
▸
Plus readback audits: walkability (pedestrian-network metrics, goldens may only improve) and dressing (defects the graph misses).
▸
Lint proves well-formedness, not quality — walks stay the human's instrument.

Shape of the system

Two sides meet at the compiler: the agent side (packages/agents + packages/cli) turns a prompt into a validated Loam document with frozen, hash-verified bespoke programs; the compiler side (packages/compiler + packages/stdlib + packages/spec) turns the document into voxels, worlds and zips — deterministically, with no model in the loop. Everything an author writes is a request (envelope, constraints, ports, zones), never absolute coordinates; a layout solver places it.

Key mechanisms: the ground contract (nothing modifies ground after it's decided — every pass declares GroundIntents, a resolver owns precedence), the SweptProfile linework engine (arc-length datum, tread law), the AuthoredProgram sandbox (model-written code, double-run byte-compared, E334 on mismatch), the flora grammar (shape programs + 17-species registry), and the intent fan-out (dials → subsystem knobs, every row total).

Pipeline — prompt to world

Agent side (model in the loop, packages/agents + cli)

Cost controls: DEFAULT_BESPOKE_BUDGET_USD = 1.00 spend stop, area-scaled program budgets (clamp(3·A/512², 3, 12) landmarks / 3–6 plugins), bounded rounds (MAX_AUTHOR_ATTEMPTS=3, MAX_COMPILE_ROUNDS=2, ≤3 program repair rounds), and revision-conversation trimming (superseded rounds collapse to one marker line — ~10× cheaper rounds). Everything except document authoring is fail-open: nothing may stop a world shipping except the authoring loop itself.

Compiler — the deterministic 10-stage pipeline (packages/compiler)

Every stage's random draws are seeded hash(worldSeed, nodePath). The ground contract cuts across stages 6–8: each pass declares GroundIntents through the GroundDriver; the resolver (resolveGround) reconciles all declarations into a frozen ground with explicit total precedence (INTENT_RANK) before any material is laid.

Emit & verification

All three world-writing paths (G1 spike emitWorld, Loam emitTerrain, Terrarium) funnel through write.ts: clean region dir → chunks saved in (z,x) order → zeroed chunk timestamps → hand-built level.dat (DataVersion 4671). Then readback: applyConnectionStates (fences), applyGrowthFaces (vines), physics lint, walkability + dressing audits. LastPlayed is stamped at install only.

The physics lint — all 27 rules

Reads the emitted world back off disk and refuses findings; defined in packages/compiler/src/emit/physics.ts (PHYSICS_RULES). Rule 27 (unsupported.multiface) landed with RUINS-PLAN WP-6 — the first rule policing a block whose whole state is its attachment.

Beyond the rules

▸
Walking agent — a 1×2 player body flood over standable ground (3-block drops); traversal.no_start / traversal.unreachable are the rules that see a town nobody can climb.
▸
palette/registry/biome checks + block-entity pairing — the lint also validates the palette against the live Minecraft registry.
▸
Invoked by programs/verify.ts (gate step: physics over a scratch world) and tests — not the write path.
▸
Honest limit (DESIGN.md): 1,010 stub retaining walls, 314 stair lanterns and an 80%-pavement quarter are all perfectly legal — the lint proves well-formedness, not quality; walks are the only instrument that sees the rest.
