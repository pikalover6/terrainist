   run `CC_BINARY=$(which claude) python3 tools/cc-effort-probe/probe.py`
   (free, offline); (b) Kai can join the session from the desktop app; (c)
   subagent types render (`impl-opus-low` etc.); (d) full suite green;
   (e) one end-to-end: box commits a trivial change → laptop pulls,
   compiles, installs a world.
6. **Laptop bridge — git, not file transfer:** worlds are byte-deterministic
   from (commit, doc, seed), so the box ships commits, never region files.
   Laptop side: pull → `terrainist compile/devworld/terrarium` → `install
   --replace` (seconds). Feedback path: `review-import` session JSON +
   referenced screenshots committed to `feedback/<date>/` on a branch or
   main; the cloud session treats that directory as its inbox. GLM-authored
   docs are small JSONs — commit them too. Optional: Tailscale for direct
   SSH/remote control of a small local session; NOT required for the loop.
   No inbound access to the laptop is needed in the base design.
7. **Concurrency/plan caution:** box sessions share Kai's subscription
   limits with local sessions; don't run heavy fleets in both places at once.
